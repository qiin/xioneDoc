# 边栏个性化设置开关

个人资料页有一张「左侧边栏个人设置」卡片，让用户自己勾选侧边栏要显示哪些区域。

默认所有非超级管理员账号（管理员和普通用户）都能看到并使用这张卡片。如果你不希望
用户自行调整侧边栏布局，可以在后台统一关闭。

## 配置位置

系统设置 → 运营 → 系统行为 → **Allow Sidebar Personalization**

| 状态 | 效果 |
| --- | --- |
| 打开（默认） | 管理员和普通用户都能自定义侧边栏 |
| 关闭 | 管理员和普通用户都看不到这张卡片，统一展示管理员配置的默认侧边栏 |

超级管理员账号不受这个开关影响——超级管理员本来就没有这张卡片。

## 关闭后，用户之前的个性化设置会怎样

不会丢失。关闭开关只是暂时不展示、不生效；用户此前保存的偏好仍留在数据库里，重新
打开开关后会自动恢复，不需要用户重新设置一遍。
