# 创建与管理 API 密钥

网关的 API 密钥（也叫令牌）用于调用 `/v1/*` 接口，和你账号的登录密码是两回事——
密钥泄露只影响调用额度，不会暴露账号本身。

## 创建密钥

登录后进入「API 密钥」页面，点新建，可以设置：

- **名称**：方便自己识别用途，比如给不同项目分别建一个
- **额度限制**：给这个密钥单独设一个消费上限，超过就自动停用，和账号总额度分开算
- **有效期**：到期自动失效，长期项目可以留空表示不过期
- **可用模型**：限制这个密钥只能调用哪些模型，其他模型会被拒绝

## 密钥状态

| 状态 | 含义 |
| --- | --- |
| 已启用 | 正常可用 |
| 已禁用 | 手动关闭，可以随时重新启用 |
| 已过期 | 超过设置的有效期，需要延长有效期或新建 |
| 已耗尽 | 密钥自己的额度用完了，即使账号还有余额也调不通 |

「已耗尽」是最容易被误判成账号没钱的情况——先看密钥自己的额度，再看账号总额度。

## 调用方式

和 OpenAI 官方 API 完全兼容，把 `base_url` 换成你的网关地址，`api_key` 换成这里
生成的密钥即可，SDK、客户端不需要改代码。
