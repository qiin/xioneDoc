# 计费与额度说明

## 额度是什么单位

网关内部按「额度」（quota）计费，1 单位额度对应固定的美元金额，由管理员在后台设置
换算比例。充值页面显示的是折算后的美元/代币数字，方便理解，底层记账仍然是额度。

## 账号额度 vs 密钥额度

- **账号额度**：登录用户整体的余额，充值增加，调用模型消费
- **密钥额度**：给单个 API 密钥单独设的上限，是账号额度之上的**再一层限制**，
  两者互不影响对方——密钥额度归零不会扣账号额度，账号额度归零所有密钥都会停

## 分组与倍率

不同用户分组可以配置不同的价格倍率（分组倍率），常见用法：

- 给内部测试账号设一个免费或打折分组
- 给不同付费等级的用户设不同的模型访问权限和价格

充值时的「分组倍率」和模型调用时的「分组倍率」是两套独立配置，充值页面显示的价格
已经按你所在分组算好了，不需要自己换算。

## 账单在哪看

个人资料页「使用日志」能看到每次调用花了多少额度、用了哪个模型；「充值记录」能看到
每笔充值的支付方式、金额和状态。管理员在后台能看到全平台的统计。
