# 欢迎使用 XiOne 文档

XiOne 是基于开源项目 [new-api](https://github.com/QuantumNous/new-api) 部署的 AI API
网关：统一接入 40+ 上游模型供应商，提供用户管理、计费、限流和管理后台。

本文档介绍这套部署的**使用方式**和**管理后台配置**，不是 new-api 项目本身的开发文档
（那部分请参考 new-api 官方仓库）。

## 这份文档能帮你做什么

- 了解不同的部署方式（Docker / 源码编译）
- 配置支付网关，让用户可以在线充值
- 使用管理后台里的各项开关，调整站点行为
- 查找常见问题的答案
