# 易支付（支付宝 / 微信）配置

面向国内用户的传统在线支付方式，通过第三方易支付接口聚合支付宝和微信支付。

## 前置条件

需要一个第三方易支付服务商的账号，拿到：

- 支付网关地址
- 商户 ID
- 商户密钥

## 后台配置步骤

打开「系统设置 → 计费与支付 → 支付网关」：

| 字段 | 说明 |
| --- | --- |
| 支付网关地址 | 服务商提供的接口地址 |
| 商户 ID | 服务商分配的商户号 |
| 商户密钥 | 服务商分配的密钥，用于签名验证 |
| 价格 | 每单位额度对应的人民币金额 |
| 最低充值 | 起充金额（美元） |

## 付款方式列表

保存后还需要在「付款方式」表格里添加具体的支付渠道条目（比如支付宝、微信），
每一条对应易支付接口里的一个 `type` 参数值，服务商文档会给出可用的类型清单。

## 回调地址

易支付的回调是网关自动处理的固定路径，不需要额外配置——只要网关地址本身能被
公网访问到，回调就能正常送达。
