# Creem 配置

适合订阅制场景的支付渠道，支持一次性支付和多个预设商品档位。

## 后台配置步骤

系统设置 → 计费与支付 → 支付网关，找到 Creem 相关字段：

| 字段 | 说明 |
| --- | --- |
| API Key | Creem 后台生成的密钥 |
| Webhook 密钥 | 校验回调来源 |
| 测试模式 | 打开后走 Creem 的沙盒环境，方便联调 |
| 商品列表 | 一组预设的充值档位，每个档位对应固定的价格和额度 |

商品列表按 JSON 格式配置，每个条目包含商品名称、Creem 侧的 Product ID、价格和
到账额度，用户充值时直接选档位，不需要自己输入金额。

## Webhook 配置

和 Stripe 类似，需要在 Creem 后台配置回调地址并核对签名密钥，否则支付成功后
额度不会自动到账。
