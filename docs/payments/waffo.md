# Waffo / Waffo Pancake 配置

Waffo 系列面向不方便走传统支付渠道的场景，无需注册公司即可收款，Waffo 本身
作为登记商户（Merchant of Record）承担部分合规和税务处理。

## Waffo（标准版）

系统设置 → 计费与支付 → 支付网关，Waffo 相关字段：

| 字段 | 说明 |
| --- | --- |
| API Key / 私钥 / 公钥证书 | Waffo 后台生成的一组凭证 |
| 沙盒模式 | 打开后用测试环境的凭证，字段和生产环境是分开的两套 |
| 商户号 | Waffo 分配的商户标识 |
| 单价 / 最低充值 | 计费参数 |
| 支付方式列表 | Waffo 支持的具体收款方式，比如信用卡、当地钱包 |

## Waffo Pancake（托管结账）

Pancake 是 Waffo 的托管结账变体，用户跳转到 Waffo 提供的结账页面完成支付，
网关不需要自己渲染支付表单。

配置流程：

1. 在后台填入商户号和私钥
2. 用「创建店铺与产品」功能一键生成 Store 和默认商品，或者手动在 Waffo 后台创建
3. 回填生成的 Store ID 和 Product ID
4. 分别为测试模式和生产模式在 Waffo 后台登记对应的 Webhook 地址——两套环境的
   回调地址不同，登记反了会导致测试流量误充到生产账户，或者生产支付收不到回调
